## 💡 Solution Format

Each problem follows our **standardized template** for maximum learning:

```markdown
# Problem Title
**Difficulty:** Easy ✅ | Medium ⚡ | Hard 🔥

## 🔹 Problem Statement
Clear problem description with context

## 🔹 Examples  
Multiple test cases with explanations

## 🔹 Constraints
Input limitations and edge cases

## 🔹 Intuition & Logic
High-level approach and reasoning

## 🔹 Approaches
1. Brute Force → Optimized solutions
2. Multiple algorithms with trade-offs

## 🔹 Java Code
Clean, well-commented implementations

## 🔹 Complexity Analysis
Time & Space complexity for all approaches

## 🔹 Edge Cases
Important corner cases to consider

## 🔹 Follow-Up Questions
Common interviewer extensions and variations
```

## 📈 Study Schedule

### 🗓️ 30-Day Interview Prep Plan

<details>
<summary><strong>Week 1: Foundation Building</strong></summary>

**Days 1-2: Arrays Fundamentals**
- Two Sum, Missing Number, Majority Element
- Practice: Two pointers, HashMap usage

**Days 3-4: Basic Linked Lists** 
- Reverse List, Middle Element, Detect Cycle
- Practice: Fast/slow pointer technique

**Days 5-7: String Basics + Review**
- Valid Parentheses, Longest Substring
- Review week 1 problems, identify patterns

</details>

<details>
<summary><strong>Week 2: Intermediate Patterns</strong></summary>

**Days 8-10: Advanced Arrays**
- 3Sum, Container with Water, Rotate Image
- Practice: Complex two pointers, matrix operations

**Days 11-12: Tree Traversals**
- Inorder, Preorder, Level Order traversals
- Practice: DFS vs BFS approaches

**Days 13-14: Stack Applications**
- Next Greater Element, Daily Temperatures
- Practice: Monotonic stack pattern

</details>

<details>
<summary><strong>Week 3: Graph & Advanced Topics</strong></summary>

**Days 15-17: Graph Algorithms**
- Number of Islands, Course Schedule, Clone Graph
- Practice: DFS, BFS, topological sort

**Days 18-19: Heap Applications** 
- Kth Largest, Top K Frequent, Median Stream
- Practice: Min/max heap usage

**Days 20-21: Advanced Trees**
- LCA, Diameter, Serialize/Deserialize
- Practice: Complex tree operations

</details>

<details>
<summary><strong>Week 4: Hard Problems & Mock Interviews</strong></summary>

**Days 22-24: Hard Array/String Problems**
- First Missing Positive, Minimum Window Substring
- Practice: Advanced algorithms

**Days 25-26: Hard Tree/Graph Problems**
- Word Ladder, Binary Tree Max Path Sum
- Practice: Complex graph traversals

**Days 27-30: Mock Interviews & Review**
- Timed problem solving (45 min each)
- Review weak areas, practice explaining solutions

</details>
