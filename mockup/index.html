Two Sum

Problem Statement

Given an array of integers and a target sum, find indices of the two numbers such that they add up to the target. Assume exactly one solution exists, and you can't use the same element twice.

Examples

Input
nums = [2, 7, 11, 15], target = 9

Output
[0, 1]  // 2 + 7 = 9
Input
nums = [3, 3], target = 6

Output
[0, 1]  // duplicate handling

Constraints

  • 2 ≤ nums.length ≤ 10⁵
  • −10⁹ ≤ nums[i] ≤ 10⁹
  • Exactly one valid solution exists

Edge Cases

  • Negative numbers
  • Duplicate values in array
  • Array of size exactly 2

Approach 1: Brute Force

Check every pair using nested loops. Simple but slow.

Time O(n²)
Space O(1)

Approach 2: HashMap (Optimal) ⭐

One pass. Store complement → index. O(1) lookup per element.

Time O(n)
Space O(n)

Approach 3: Two Pointers (Sorted)

Sort first, converge from both ends. Needs index remapping.

Time O(n log n)
Space O(n)

Interviewer Follow-ups

What if the array is sorted?

Use Two Pointers — O(n) time, O(1) space. No HashMap needed.

What if there are multiple valid pairs?

Modify to collect all pairs instead of returning on first match.

What if extra space is not allowed?

Only feasible for sorted arrays via two pointers.

What if numbers are streamed (online)?

Maintain HashMap while processing input in real-time.

☕ Java — Brute Force (Free)
class Solution {
    public int[] twoSum(int[] nums, int target) {
        // Brute force: check every pair
        for (int i = 0; i < nums.length; i++) {
            for (int j = i + 1; j < nums.length; j++) {
                if (nums[i] + nums[j] == target) {
                    return new int[] { i, j };
                }
            }
        }
        return new int[] { -1, -1 };
    }
}
☕ Java — HashMap Optimal ⭐
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer,Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            if (map.containsKey(complement))
                return new int[] {map.get(complement), i};
            map.put(nums[i], i);
        }
        throw new IllegalArgumentException();
    }
}
