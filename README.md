## 🚀 How to Use This Repository

### 1. **Browse by Topic**
Navigate to the category you want to practice (arrays, graphs, trees, etc.)

### 2. **Choose Your Level**  
- **🟢 Easy ✅** - Start here if you're new to DSA
- **🟡 Medium ⚡** - Good for interview preparation  
- **🔴 Hard 🔥** - Advanced problems for top-tier companies

### 3. **Study the Structure**
Each problem follows this format:
- **Problem Statement** - Clear description
- **Examples** - Multiple test cases with explanations
- **Constraints** - Input limitations
- **Intuition & Logic** - High-level approach
- **Approaches** - Multiple solutions (Brute Force → Optimal)
- **Java Code** - Clean, well-commented implementation
- **Complexity Analysis** - Time & Space complexity table
- **Edge Cases** - Important corner cases to consider
- **Follow-up Questions** - Common interviewer extensions

### 4. **Practice Methodology**
1. **Read** the problem statement carefully
2. **Think** about the approach before looking at the solution
3. **Implement** your solution
4. **Compare** with provided solutions
5. **Analyze** time/space complexity
6. **Consider** edge cases and follow-ups
